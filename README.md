# Password-Generate-Page

A simple and user-friendly web tool designed to generate strong, secure, and customizable passwords.

## 🚀 Features

* **Fully Customizable**: Choose password length and toggle options for numbers, special characters, uppercase, and lowercase letters.
* **Modern UI**: Clean and responsive design styled with vanilla CSS.
* **Tech Stack**: Built using TypeScript and React (TSX).

## 🛠️ File Structure

* `PasswordApp.tsx` — Core application component containing the generator logic and layout.
* `index.ts` — Main entry point of the project.
* `password.css` — Custom styling and visual presentation.

## 💻 Getting Started

Follow these steps to run the project locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/LonelyGR/Password-Generate-Page/tree/main
   ```
2. Navigate into the project directory:
   ```bash
   cd Password-Generate-Page
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```
